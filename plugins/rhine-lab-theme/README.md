## Highlights (v4.0.0)

- **Dual-Mode Workspace & 1:1 `RhineLabUI` 3D CAD Archive Extraction (`archiveMode: true`)**:
  - Switch freely anytime between **标准工作台 (`STANDARD`)** and **3D 档案提取模式 (`ARCHIVE`)** via the bottom-right HUD pill (`工作台 | 档案模式`), sidebar/header `◈` trigger, or `Ctrl+Shift+A` / `Cmd+Shift+A`.
  - Features the authentic `archive-cassette.glb` and 6-layer `archive-assembly.glb` CAD models, `RoomEnvironment` studio IBL, `SharedDepthAO` + `SharedDepthBokeh` + `SMAAPass` post-processing, real `Frosted_Polymer` directional refraction blur with top-to-bottom decryption scan, 3D-projected `InspectionOverlay`, per-line `DocumentDecryption` redaction wipe, and radial `HudProjection`.
  - Projects live Atrium conversations, plugins, skills & memory, MCP connectors, and automations into the 5-column × 8-row physical cassette array with click/drag/wheel/keyboard navigation, `/` quick index search, Detail view with one-click **"在工作台打开 →"**, and 360° 6-layer exploded CAD Object Study.
- **Entry Confirmation Gate (`confirmEntry: true`)**:
  - Dedicated terminal gate (`INTERNAL DATABASE / READY`, framed `点击进入 →` button, `静音进入`, and `跳过片头直接进入 ↗`) unlocking Web Audio synchronously on entry before the 5-act boot sequence plays.
- **Archival Daylight & Mineral Slate Polarities + Web Audio Tactile HUD**:
  - Warm Limestone Paper (`#E8E5E1`) / Deep Mineral Slate (`#11181B`), inverted architectural CTAs, vertical ruler-tick hover/active rails, 6-digit rolling `HH:MM:SS` timer, crosshair click lock, and Web Audio glass sound effects (`SFX` / `MUTE`).
