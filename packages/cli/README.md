# @atrium-ai/cli

Cross-platform terminal CLI for **Atrium** (`Windows`, `macOS`, `Linux`).

## Install

```bash
npm install -g @atrium-ai/cli
```

Then launch from any directory:

```bash
atrium
```

## Quick Commands

```bash
atrium                       # Start interactive REPL (with first-run setup wizard)
atrium login                 # Sign in with Atrium Account (Email / Google / GitHub)
atrium doctor                # Inspect runtime, provider, Git, and MCP diagnostics
atrium -p "Summarize repo"   # One-shot non-interactive prompt (supports piped stdin & --json)
```
